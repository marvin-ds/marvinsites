# 1. Quatro níveis não significam quatro cards públicos

A escada:

- R$399 + R$97;
- R$599 + R$197;
- R$1.497 + R$297;
- R$2.997+ + R$497+;

é uma arquitetura progressiva de valor.

A home atual pode apresentar apenas os níveis adequados à fase comercial vigente.

# 2. Oferta pública atual

A produção pós-COM-G1 apresenta:

- R$399 + R$97/mês;
- R$599 + R$197/mês.

Os níveis seguintes podem ser recomendados em diagnóstico/proposta.
