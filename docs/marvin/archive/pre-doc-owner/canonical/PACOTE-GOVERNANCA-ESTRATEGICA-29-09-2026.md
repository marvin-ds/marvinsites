-   dever de contestação;
-   anti-sycophancy;
-   confiança epistemológica;
-   objetivo → gargalo → prioridade antes de execução;
-   Revenue Before Complexity;
-   custo de oportunidade;
-   Better Alternative Duty;
-   Wrong Question Protocol;
-   BUILD / ADAPT / BUY / MANUAL / DON'T DO YET;
-   ACCELERATE / CONTINUE / FIX / PAUSE / KILL;
-   gestão por indicadores antecedentes;
-   revisão semanal;
-   Stop Doing;
-   meta econômica sem autorização para promessas falsas, spam ou
    atalhos imprudentes.
