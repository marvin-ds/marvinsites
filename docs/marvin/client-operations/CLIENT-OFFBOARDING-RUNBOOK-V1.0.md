# Marvin Sites — Client Offboarding Runbook

**VERSÃO:** 1.0
**DATA-BASE:** 05/09/2026
**STATUS:** CANÔNICO OPERACIONAL
**GOVERNA:** encerramento de serviço, transferência e desligamento.

---

# 1. Princípio

> **Sem prisão artificial e sem desligamento improvisado.**

# 2. Pré-condições

Confirmar:

- pedido;
- data;
- aviso;
- pendências;
- contrato;
- plano;
- domínio;
- destino.

# 3. Domínio

Domínio permanece do cliente.

Nunca reter como garantia.

# 4. Conteúdo

Separar:

- conteúdo do cliente;
- assets do cliente;
- IP Marvin;
- licenças de terceiros.

# 5. Código

Aplicar contrato:

- licença;
- exportação;
- cessão se prevista;
- migração paga quando aplicável.

Não prometer propriedade exclusiva de biblioteca reutilizável Marvin.

# 6. Dados

Exportar o que for devido:

- leads;
- forms;
- relatórios;
- configurações.

Respeitar LGPD e retenção.

# 7. Analytics

Remover acessos Marvin quando apropriado.

Contas do cliente continuam com ele.

# 8. DNS

Se migrar:

- receber destino;
- inventário;
- alterar;
- validar;
- e-mail preservado.

# 9. Netlify

Após migração/encerramento confirmado:

- remover domínio quando necessário;
- arquivar/desativar projeto conforme política;
- preservar histórico administrativo mínimo.

# 10. Repo

Arquivar conforme contrato e política.

Não apagar imediatamente sem retenção aprovada.

# 11. Secrets

Revogar credenciais Marvin/cliente não mais necessárias.

# 12. Billing

Encerrar recorrência na data correta.

Registrar último pagamento.

# 13. Confirmação

Enviar resumo:

- data;
- domínio;
- destino;
- arquivos;
- acessos;
- cobrança;
- término.

# 14. Critério de saída

- cliente não perde domínio;
- e-mail funciona;
- cobrança encerrada;
- acessos revogados;
- dados tratados;
- registro concluído.
